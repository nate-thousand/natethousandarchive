# Design System

Platform-agnostic design system documentation. Defines the long-term vision independent of Bootstrap or any future implementation.

## Contents

| Document | Description |
|----------|-------------|
| `DESIGN_SYSTEM.md` | System overview and migration strategy |
| `DESIGN_PRINCIPLES.md` | Core design principles |
| `ACCESSIBILITY.md` | Accessibility standards |

## Relationship to Bootstrap

Bootstrap 5.0.2 is the **current implementation layer**. These documents define the **target experience**. When Bootstrap is replaced, implementation changes; these documents do not.
