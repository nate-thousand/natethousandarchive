# Patterns

Reusable UX patterns — implementation-agnostic guidance. Map to Bootstrap via component docs and `bootstrap/COMPONENT_MAPPING.md`.

| Pattern | Document |
|---------|----------|
| Page layouts | `PAGE_LAYOUTS.md` |
| Dashboards | `DASHBOARDS.md` |
| Forms (multi-field flows) | `FORMS.md` |
| Search | `SEARCH.md` |
| Filters | `FILTERS.md` |

Also see component docs for **Empty states**, **Loading states**, and error guidance below.

## Cross-Cutting Patterns

| Pattern | Guidance |
|---------|----------|
| Authentication | Dedicated auth layout — minimal chrome, single column, clear errors |
| Settings | Grouped sections with save per section or sticky save bar |
| Error states | Inline for field errors; alert or dedicated panel for page-level failures |
| Empty states | `components/EMPTY_STATES.md` |
| Loading states | `components/LOADING_STATES.md` |
