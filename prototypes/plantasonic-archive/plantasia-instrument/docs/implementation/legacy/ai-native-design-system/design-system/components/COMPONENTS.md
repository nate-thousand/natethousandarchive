# Components

## Purpose

Document reusable component decisions without generating application code.

## Component Standard

Each reusable component should define:

- Purpose
- Anatomy
- Variants
- States
- Token usage
- Accessibility requirements
- Product examples

## Starter Candidates

- Button
- Form field
- Card
- Modal
- Navigation
