# Patterns

## Purpose

Capture reusable flows and compositions that combine components, tokens, content, and interaction rules.

## Pattern Standard

Each reusable pattern should define:

- Problem solved
- When to use
- Structure
- Required components
- Accessibility notes
- Examples
- Anti-patterns

## Starter Candidates

- Landing page hero
- Dashboard overview
- Settings form
- AI chat interaction
- Case study page
