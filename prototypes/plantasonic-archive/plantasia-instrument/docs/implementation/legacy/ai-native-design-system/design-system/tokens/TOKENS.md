# Tokens

## Purpose

Define reusable design values that can map into Figma variables, CSS variables, Bootstrap variables, or future implementation systems.

## Standard

- Name tokens semantically.
- Document intent before raw value.
- Add examples only when the token has a known use.
- Avoid adding product-specific decorative values too early.

## Starter Categories

- Color
- Typography
- Spacing
- Radius
- Motion
- Elevation
