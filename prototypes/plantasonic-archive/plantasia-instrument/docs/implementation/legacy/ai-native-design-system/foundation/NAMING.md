# Naming

## Folder Names

Use kebab-case for folders.

Examples:

- `design-system/`
- `project-starter/`
- `case-study/`

## Core Documents

Use `SCREAMING_SNAKE_CASE.md` for core framework artifacts.

Examples:

- `PROJECT_BRIEF.md`
- `DESIGN_SYSTEM_MAP.md`
- `PROJECT_RETRO.md`

## Design System Names

Use semantic names before value names.

Good:

- `color-surface-primary`
- `space-section-lg`
- `radius-control-md`

Avoid:

- `blue-500` as the only public name
- `big-spacing`
- `rounded-thing`

## Promotion Names

Name promoted items by the recurring problem they solve, not the product where they were discovered.
