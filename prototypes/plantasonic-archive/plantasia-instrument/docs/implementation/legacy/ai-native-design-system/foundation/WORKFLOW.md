# Workflow

## Design OS Loop

```text
Start project -> inherit framework -> build product -> extract reusable lessons -> improve Design OS
```

## Start Project

Create the three required artifacts:

1. `PROJECT_BRIEF.md`
2. `DESIGN_SYSTEM_MAP.md`
3. `PROJECT_RETRO.md`

## Inherit Framework

Use existing principles, tokens, components, patterns, prompts, and templates before inventing new ones.

## Build Product

Build in the product repository. Keep product-specific code, assets, content, and brand language there.

## Extract Lessons

At a milestone or project close, ask:

- What did this project reuse?
- What did this project invent that could help another product?
- What should stay product-specific?
- What one token, pattern, prompt, or template should be promoted?

## Improve Design OS

Promote reusable improvements back into the smallest relevant place in this repository.
