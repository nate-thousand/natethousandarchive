Plantasia needs the Vite dev server

The app is not broken. MIDI and performance features are fine — you are just on the wrong server.

This app is TypeScript + React and cannot run through Live Server, “Open with Live Preview”, or by opening index.html directly.

In the terminal, from the plantasia-ecosystem folder:

npm install
npm run dev

Then open the URL Vite prints — usually http://localhost:5180 (look for the v2.1 badge in the top bar).
